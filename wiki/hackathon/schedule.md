# Schedule

Timetable for OYU CyberAI Hackathon 2026, 17–18 Nov 2026, Odlar Yurdu University.

| Time | Activity | Content |
|---|---|---|
| 09:00–10:00 | Registration | Badges, breakfast, networking |
| 10:00–10:30 | Team briefing | Goals, rules, tracks, mentors and jury introduced |
| 10:30–11:00 | Team finalization | Teams finalized, track chosen |
| 11:00–11:30 | Opening ceremony | Speakers (overlaps Sprint I) |
| 11:00–14:00 | **Building Sprint I** | Problem analysis, solution concept, architecture, first prototype |
| 14:00–15:00 | Lunch | |
| 15:00–18:00 | **Building Sprint II** | Coding, AI/ML, database, interface, security mechanisms |
| 18:00–19:00 | Mentor checkpoint | Short mentor meetings and feedback |
| 19:00–22:00 | **Building Sprint III** | Finish MVP, testing, demo prep |
| 22:00–22:30 | **Product submission** | Product name, problem, solution, demo/MVP link, chosen track |
